# Sole Engine

AI for WordPress

By [Sole Computer](https://sole.computer)

WordPress allows plugins and themes to use a common provider for AI: language models and embeddings alike. Sole Engine is that provider.

Get an API key from your [Sole Account](https://account.sole.computer) and your WordPress site is supplied with the AI it needs.

All of Sole Computer's plugins draw their intelligence from this same engine.

When your site needs an AI function, the Sole Engine plugin talks to an API that processes the request with state of the art AI models.

For semantic capabilities, Sole Engine runs an external vector database service that automatically indexes your posts. Advanced semantic search becomes possible even when your site's own hosting is far too restricted to run one itself.

Sole Engine is built to our barefoot standards: problems are prevented by making them structurally impossible, and where that isn't enough, it fails gracefully. If the plugin or the service ever fails, it steps aside, and your site keeps running.

## Requirements

- WordPress 6.5 or later
- PHP 8.3 or later
- WordPress 7, specifically for registration as a native AI Client provider (the plugin itself runs on 6.5+; that one role is a WordPress 7 capability)

## Installation

Install Sole Engine from the [WordPress.org plugin directory](https://wordpress.org/plugins/sole-engine/).

This repository is a read-only mirror of released versions, not the installation source.
